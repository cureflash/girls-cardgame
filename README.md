# girls-cardgame

昔作ったトランプ対戦ゲームを、魔法少女キャラクターを使う形でブラウザゲーム化した試作です。

## 現在のキャラクター

- 鹿目まどか: 受ける戦闘ダメージを常に1軽減
- 巴マミ: 初期手札+1枚

## 実装済みの記憶上のルール

- デッキがライフを兼ねる。デッキが先になくなった側が負け。
- 数字/絵札の値が使い魔の攻撃力。J=11, Q=12, K=13。
- 先攻1ターン目は攻撃不可。
- 9/10は生贄1枚、J/Q/Kは生贄2枚で召喚。
- ♠は戦闘中に手札から出し、その数値を戦闘値へ加算。双方チェーン可能。
- Aはチェーン終了後に使用でき、その戦闘ダメージを0にする。
- ♥は儀式召喚。♥の数値より小さい手札の使い魔を、通常の生贄を無視して召喚する。召喚権を使う。
- ダメージを受けると、その枚数だけデッキを減らす。`ceil(ダメージ/3)` 枚を手札へ、残りを墓地へ送る。
- JOKERは使用時に以下のどちらかを選ぶ。
  - 全フィールドの使い魔を破壊。
  - 自分の場の使い魔を全て生贄にし、その攻撃力合計を持つ使い魔にする。
- ♦/♣の固有能力は、当時のルールを思い出せていないため未実装。

## 暫定実装

記憶から確定できなかった部分だけ、遊べる状態にするため設定値として分離しています。

- 初期手札5枚（マミは6枚）
- 場は5枠
- 1ターン1回攻撃
- 相手の場が空なら直接攻撃
- 同値戦闘は双方墓地
- ダメージでめくれたカードは、上から必要枚数を手札にし、残りを墓地へ
- JOKERは各デッキ1枚

これらは `src/config.js` と `src/engine.js` の該当箇所で変更できます。

## AI

かなり単純です。

- 召喚可能な最大攻撃力のカードを優先
- 必要なら弱い場札を生贄にする
- 最大攻撃力の使い魔で攻撃
- チェーンでは、逆転に必要な最小の♠を使う
- Aは4ダメージ以上を受ける時に使う
- 不利な盤面ではJOKERの全破壊を使う場合がある

## 画像差し替え

ゲームロジックと画像は分離しています。

- まどか側: `assets/cards/madoka/`
- マミ側: `assets/cards/mami/`
- キャラクター: `assets/characters/`

カード画像は `S8.png`, `H10.png`, `DQ.png`, `CK.png`, `JOKER.png` のように置くだけです。存在しない場合は通常のトランプ表示になります。

キャラクター画像は `assets/characters/madoka.png` と `assets/characters/mami.png` です。

## 起動

ES Modulesを使うため、ローカルHTTPサーバーで開いてください。

```bash
npm run serve
```

その後 `http://localhost:8000` を開きます。

## テスト

```bash
npm test
```
